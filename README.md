# ACTI 学术性格测试

双击 index.html，用 Edge、Chrome 等现代浏览器打开即可使用。无需安装、联网或服务器。请将 index.html、style.css、data.js、app.js 放在同一文件夹。

包含 32 道二选一题、16 型图鉴、答题续存、历史结果、复制分享。题目与档案依据 idea.md 原创补齐，可在 data.js 中修改。

每轴 8 题，选 A 为该轴第一侧加 1，选 B 为第二侧加 1。4:4 平票以 ? 显示，列出所有相容类型。由于每轴总分为 8，分差 ≤1 仅可能为平票。第 1–4 题与第 17–20 题为一致性校验对，出现不一致仅提示彩蛋。

进度和最近 50 次结果存放在当前浏览器的 localStorage 中。换浏览器、移动文件或清理浏览器数据可能导致原记录不可见。浏览器禁止存储时仍可完成当前测试，但关闭后不能恢复。

所有内容仅供娱乐，不评价学术能力、不预测毕业结果、不构成心理诊断。第一版没有图片导出功能，可复制结果分享语。
